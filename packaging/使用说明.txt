硬件温度监控 — 使用说明
========================================

体积约 0.8 MB，绿色免安装，不联网、不上传任何数据。


一、怎么打开
----------------------------------------
1. 把整个文件夹解压到任意位置（桌面、D 盘都行，
   但不要放进 C:\Program Files，那里普通权限写不进文件）。
2. 双击 HardwareTemp.exe。
3. 弹出「用户账户控制」窗口：
   · 点「是」→ CPU 温度和显卡温度都显示（推荐）
   · 点「否」→ 照样能开，但只显示显卡温度，CPU 那栏是 --

   为什么要点「是」：Windows 从系统底层读 CPU 温度必须经过
   一个内核驱动，这一步需要管理员权限，属于正常机制。

4. 想放到桌面：右键 HardwareTemp.exe
   → 发送到 → 桌面快捷方式。


二、第一次运行可能遇到的提示
----------------------------------------
· 出现「Windows 已保护你的电脑」蓝框：
  点左侧「更多信息」→「仍要运行」。
  （原因：程序没有购买数字签名证书，不是病毒。）

· 杀毒软件提示风险 / 拦截：
  选「允许」或「添加信任」。程序读取温度时会加载一个
  硬件监控驱动（WinRing0），这个行为容易触发加密告警，
  但它只读取传感器寄存器，不改系统设置。


三、界面说明
----------------------------------------
· 温度颜色：<70℃ 绿色 / 70-85℃ 黄色 / >85℃ 红色
· 右上角「置顶」：把窗口固定在所有窗口最上层
· 按住顶部拖动可移动窗口，关闭后下次打开记住位置
· 下方曲线：最近 60 秒的温度趋势
· 默认每秒刷新一次
· 关闭程序：点右上角「✕」，或直接按 Esc 键


四、系统要求
----------------------------------------
· Windows 10（1903 及以上）/ Windows 11，64 位
· .NET Framework 4.8（Windows 10/11 系统自带，一般无需安装）


五、文件夹里的东西
----------------------------------------
必须保留：
  HardwareTemp.exe          主程序
  LibreHardwareMonitorLib.dll  硬件传感器库（离线，不联网）

运行后自动生成的，可以忽略或删除：
  app.log        运行日志（出问题时发给我看）
  settings.txt   窗口位置等设置
  HardwareTemp.sys  临时加载的硬件驱动，关掉程序后可删


六、打不开怎么办
----------------------------------------
1. 先看同目录下的 app.log，把最后几行发给作者。
2. 确认是不是解压到 Program Files 之类的受保护目录，换个位置再试。
3. 确认系统是 64 位（本程序只支持 64 位 Windows）。
